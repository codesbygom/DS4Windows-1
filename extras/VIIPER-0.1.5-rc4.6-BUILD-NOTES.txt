This release fixes bounded virtual DualShock 4 V3 feedback admission and
feedback reconnect ownership. Its fixed-capacity ring preserves distinct
accepted commands and stops, folds only eligible exact pending repeats, and
reports no-space instead of silently accepting and dropping a full-queue
command. One slot is reserved for a motor stop. Callback registration and
retirement use generation ownership so an old session cannot detach or
deliver into a replacement session.

The queue remains bounded: this is not an arbitrary-rate lossless transport,
nor a promise that every host retries a rejected USB output. Input mapping,
USB/IP transport, authentication, native DualSense command semantics and
Nintendo HD-rumble encoding remain unchanged by this broker revision.

CFBK v1 uses the shared Windows QPC clock. Windows suites exercise real Stop/ACK
scenarios; Linux explicitly rejects the unavailable clock instead of pretending
a different epoch is equivalent. The canonical feedback/retirement path is
Windows-specific.

with its MIT COPYING grant. Notices include that grant and the complete copied
systray Apache-2.0 license. The aggregate's module version changed; its actual
